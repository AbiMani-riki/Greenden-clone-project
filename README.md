# 🌿 Greenden – Plant Shopping Website

Greenden is a modern and responsive plant shopping website developed to provide users with a simple, smooth, and enjoyable online shopping experience. The website features an attractive design, clean layout, and easy navigation, allowing visitors to explore different varieties of plants.

The main objective of this project is to create a user-friendly platform where customers can discover plants, view product images, explore available options, and learn more about different products. The website uses a fresh green theme inspired by nature, creating a pleasant and welcoming shopping environment.

### ✨ Features

- **Home Page:** An attractive landing page with simple navigation, beautiful visuals, and a welcoming introduction.
- **Product Display:** Showcases different varieties of plants with attractive images, product names, and prices.
- **Responsive Design:** Adapts to different screen sizes, including mobile phones, tablets, and desktop computers.
- **Hover Effects:** Includes interactive hover animations, image transformations, and smooth transitions to improve the browsing experience.
- **Contact Page:** Provides contact information and helps visitors connect with the website.
- **User-Friendly Interface:** Offers simple navigation, organized sections, and an attractive overall layout.
- **Modern Styling:** Uses Tailwind CSS utility classes to create a clean and visually appealing website.

### 🛠️ Technologies Used

- **HTML5:** Used to structure the website and organize its content.
- **Tailwind CSS:** Used to create responsive layouts, styling, spacing, and interactive design elements.
- **CSS3:** Used for additional styling, animations, and visual enhancements.

### 🎯 Project Purpose

This project was developed as part of my frontend web development learning journey. It helped me gain practical experience in building responsive websites, understanding Tailwind CSS utility classes, implementing hover effects, arranging website sections, and improving my HTML and CSS skills.

While developing Greenden, I learned how to create structured layouts, maintain consistent styling, and make website elements look attractive across different devices. This project also improved my problem-solving abilities and gave me confidence in developing websites independently.
